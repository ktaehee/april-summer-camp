# 신청 폼 → 구글 시트 자동 입력 연결 가이드

신청 페이지에서 제출된 내용이 구글 시트
**「2026 여름 캠프 등록 (신청홈페이지)」** 탭에 자동으로 한 줄씩 쌓이도록 연결합니다.

> 이 단계는 **시트 주인(구글 계정 로그인)** 만 할 수 있습니다.
> 한 번만 설정해두면 이후로는 자동입니다. (약 5분 소요)

---

## 1. Apps Script 열기
1. 해당 구글 스프레드시트를 엽니다.
2. 상단 메뉴 **확장 프로그램(Extensions) → Apps Script** 클릭.

## 2. 코드 붙여넣기
1. 기본으로 열린 `Code.gs` 내용을 모두 지웁니다.
2. 이 폴더의 [`Code.gs`](./Code.gs) 내용을 **전부 복사해서 붙여넣기**.
3. 💾 저장(Ctrl+S).
   - 탭 이름이 「2026 여름 캠프 등록 (신청홈페이지)」과 **정확히** 같은지 확인하세요.
     다르면 코드 상단 `SHEET_NAME` 값을 실제 탭 이름으로 바꿉니다.
   - 열 제목(헤더)이 1행이 아니면 `HEADER_ROW` 숫자를 바꿉니다.

## 3. 웹앱으로 배포
1. 오른쪽 위 **배포(Deploy) → 새 배포(New deployment)** 클릭.
2. 톱니바퀴(⚙️) → **웹 앱(Web app)** 선택.
3. 설정:
   - **설명**: 아무거나 (예: 캠프 신청 수신)
   - **다음 사용자로 실행(Execute as)**: **나(Me)**
   - **액세스 권한이 있는 사용자(Who has access)**: **모든 사용자(Anyone)**
4. **배포** 클릭 → 구글 **권한 승인(Authorize)** (본인 계정으로 허용).
5. 배포 완료 화면에 나오는 **웹 앱 URL** 을 복사합니다.
   - 형식: `https://script.google.com/macros/s/XXXXXXXX/exec`

## 4. 사이트에 URL 연결
1. `src/App.jsx` 파일 맨 위의 다음 줄을 찾습니다:
   ```js
   const SHEET_ENDPOINT = ''
   ```
2. 따옴표 안에 복사한 URL을 붙여넣습니다:
   ```js
   const SHEET_ENDPOINT = 'https://script.google.com/macros/s/XXXXXXXX/exec'
   ```
3. 저장 → git 커밋·푸시하면 Vercel이 자동 배포합니다.

## 5. 테스트
- 라이브 사이트에서 신청 폼을 한 번 제출해보고,
  시트 「2026 여름 캠프 등록 (신청홈페이지)」 탭 맨 아래에 새 줄이 들어오는지 확인하세요.

---

## 들어가는 항목
신청일시 · 이름 · 나이 · 재원여부 · 레벨 · 알러지 · 초상권 동의 ·
정규 클래스 수강 여부 · 부모님 성함 · 부모님 연락처 ·
하원 장소(월수금) · 하원 장소(화목) · 특이사항

각 항목은 시트 헤더 이름과 **키워드 매칭**으로 알맞은 열에 들어갑니다.
매칭되는 헤더가 없는 항목은 **특이사항** 열에 모아서 기록되어 유실되지 않습니다.
(매칭 규칙은 `Code.gs` 상단 `FIELD_TO_HEADER` 에서 조정 가능)

## 참고
- `SHEET_ENDPOINT` 가 비어 있으면(`''`) 신청 시 **이메일 작성 창**이 열리는
  기존 방식으로 자동 대체됩니다. 시트 연결 전에도 신청은 받을 수 있습니다.
- 코드를 수정한 뒤에는 **배포 → 배포 관리 → 편집(연필) → 새 버전 → 배포**로
  재배포해야 반영됩니다. (URL 은 그대로 유지됩니다.)
