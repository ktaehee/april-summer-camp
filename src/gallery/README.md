# 📸 캠프 사진 넣는 곳

이 폴더(`src/gallery/`)에 **사진 파일을 넣기만 하면** 홈페이지 갤러리에 자동으로 나타납니다.
(파일 목록을 따로 수정할 필요 없어요.)

## 사진 추가 방법 (GitHub 웹에서 — 코딩 필요 없음)
1. GitHub 저장소에서 `src/gallery` 폴더로 이동
2. **Add file → Upload files** 클릭
3. 사진 파일을 끌어다 놓기 (여러 장 한번에 가능)
4. 아래 **Commit changes** 클릭
5. 1~2분 뒤 홈페이지 갤러리에 자동 반영 (Vercel 자동 배포)

## 지원 형식
`.jpg` `.jpeg` `.png` `.webp` `.gif`

## 참고
- 사진은 **파일 이름 순서**로 정렬됩니다. 순서를 정하고 싶으면
  `01.jpg`, `02.jpg` 처럼 숫자로 시작하는 이름을 쓰세요.
- 갤러리 비밀번호는 `src/App.jsx` 의 `GALLERY_PASSWORD` 값에서 바꿀 수 있어요.
- ⚠️ 이 방식은 "가벼운 잠금"입니다. 완벽한 비공개가 필요한 민감한 사진은
  별도 비공개 앨범(구글 포토 등)을 권장합니다.
