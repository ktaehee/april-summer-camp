# 📸 캠프 사진 넣는 곳 (날짜별)

사진은 **날짜별 폴더**로 관리됩니다.
`day1`, `day2` … 폴더에 사진을 넣으면 홈페이지 갤러리의 해당 **날짜 탭**에 자동으로 나타납니다.

```
src/gallery/
 ├─ day1/   ← 8/3 사진
 ├─ day2/   ← 8/4 사진
 └─ ...
```

## 사진 추가 방법 (GitHub 웹에서 — 코딩 필요 없음)
1. GitHub 저장소에서 `src/gallery/day2` (해당 날짜) 폴더로 이동
   - 폴더가 없으면 파일 업로드 시 경로에 `day2/` 를 직접 입력하면 새로 만들어져요.
2. **Add file → Upload files** 클릭
3. 사진 파일을 끌어다 놓기 (여러 장 한번에 가능)
4. **Commit changes** 클릭
5. 1~2분 뒤 홈페이지 갤러리 해당 날짜 탭에 자동 반영 (Vercel 자동 배포)

## 지원 형식 / 정렬
- `.jpg` `.jpeg` `.png` `.webp` `.gif`
- 각 날짜 안에서 **파일 이름 순서**로 정렬됩니다.

## 참고
- 갤러리 비밀번호는 `src/App.jsx` 의 `GALLERY_PASSWORD` 값에서 바꿀 수 있어요.
- ⚠️ 이 방식은 "가벼운 잠금"입니다. 완벽한 비공개가 필요한 민감한 사진은
  별도 비공개 앨범(구글 포토 등)을 권장합니다.
- 📦 사진이 많이 쌓이면(수백 장) 저장소·로딩이 무거워질 수 있어요.
  그때는 이미지 최적화나 외부 앨범 연동을 고려하세요.
